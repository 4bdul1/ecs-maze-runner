# Maze Runner and Pathfinding

A Python project for representing grid mazes, moving a runner through them, reading maze files, and finding a route. The repository includes pytest tests.

## Contents

- `src/` contains maze, runner, and command-line pathfinding modules.
- `tests/` contains the test suite and small example mazes.

## Run

Requires Python 3 and pytest. From the repository root:

```bash
python -m pip install pytest
PYTHONPATH=src python -m pytest
```

The maze utility and test files retain their original University of Southampton attribution and license notices.
